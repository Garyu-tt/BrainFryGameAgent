# Provenance, truth boundaries and safety (2026-11-08)

## Source lineages

1. **BrainFly/BrainWorkbench Minecraft**: historic 2026-09-19 snapshot remains in `recovery/0351/`. It is not the current executable. A separate BrainFly R62 system existed in October; its archives were marked private and its legacy brain startup guard is in place. No R62 identity, world, snapshot, GGUF model or secret is included here.
2. **BFB9000**: `sparse_runtime_r06.py` and `stability_r06.py` are copied from the isolated BFB9000 R06 / R06.1 research implementation and adapted for relative imports and an external graph path. These are computational kernels, **not** measured physiology.
3. **NOOSPHERE-FLY-001**: `flygame/research/` is the 2026-11-05 separate read-only-graph inhabitant with personal SQLite graph overlay. Platform-specific absolute paths were replaced with environment variables for a portable source snapshot. No active identity or living journal was copied.
4. **Game agent**: `flygame/agent.py` and `__main__.py` are new software glue created for this public release, not proof that the historic game fleet already used this protocol.

## What was measured

The local source dataset for the original BFB9000/Noosphere experiment was described and checked as Drosophila CNS with `N=165122`, `edges=10511038`, and CSR SHA-256 `c34efca42d074786e8fb4fe4b6723d5b15aa4d69be17b0cf457321cb2ac6e030`. The source loader does length, index, type and hash calculation checks. No raw source data are redistributed here; metadata alone cannot validate biological accuracy or licensing.

## What is synthesized

The membrane surrogate, excitability and gain, odor/sensory encoding, synthetic mini-graph, action-selection scores, training/reward signal, game controls, homeostasis and mapping from neural UID groups to actions. This code **cannot** substantiate claims of consciousness, cognitive equivalence or perfect recreation of an actual fruit fly.

## Handling

Only the source files needed for this public prototype have been selected. Excluded: `state/`, session journals, identity checkpoints, log archives, game worlds, server configuration, private language model data, unapproved large binary connectome corpora. `flygame/research/fly001.py` is a research snapshot, not a replacement or migration of the running original inhabitant. Do not instantiate a second copy of an existing identity.
